# Store & marketing kit: Last Lantern

| File | What it is |
|---|---|
| [steam-page.md](steam-page.md) | Steam page: short description (231/300 chars), long description, 20 tags, system requirements, asset sizes, content and AI disclosures, a fact-check script |
| [itch-page.md](itch-page.md) | itch.io page: settings, theme, page body for the free web demo, butler upload, web portals |
| [press-kit.md](press-kit.md) | Fact sheet, 50/100-word boilerplate, features, dev story, logo and key-art brief, **screenshot plan with exact in-game moments** |
| [trailer-script.md](trailer-script.md) | 30-second announcement trailer, beat by beat (picture / text / sound), plus the capture list |
| [pricing-and-launch.md](pricing-and-launch.md) | Price, timeline, demo strategy (free web version of night 1), wishlist funnel, launch discount, festivals, risks, **name check + alternate names** |
| [steam-integration.md](steam-integration.md) | Optional Steamworks setup (achievements via steamworks.js), Steam Cloud plan, SteamPipe depots, Steam Deck |

Tooling: `npm run package:web` (itch zip + sub-folder verification), `npm run package:desktop`,
`node tools/package-screens.mjs` (store screenshots). Release process: `production/release/launch-checklist.md`.
Roadmap: `production/milestones/v1.0.md`.

Voice guide for all copy: second person, present tense, short sentences, and warm with a little teeth ("Your
light is your life."). Use the in-world nouns: *vigil* (run), *bearer* (character), *relic* (passive), *Ash*
(meta-currency), *the Hearth* (meta shop), *the Gloom* (darkness), *shadows* (enemies). Never compare the game to
another title by name in store copy, and never borrow another game's logos, characters or look.
