## Regenerating the store art (screenshots, capsules, key art, gameplay capture)

All store art is **captured from the real game** by `tools/package-screens.mjs` and composed with the shipping
title logo. Nothing is painted over. Re-run it whenever the visuals change:

```bash
npm run build                                   # or: npx vite build --outDir <dir>  and pass --dist <dir>
node tools/package-screens.mjs                  # screenshots + plates + capsules  → production/release/store-art/
node tools/package-screens.mjs --video-only     # 12 s gameplay capture (mp4 / webm / gif), slow under SwiftShader
node tools/package-screens.mjs --only horde,boss          # re-shoot some moments (names below)
node tools/package-screens.mjs --no-capture               # re-compose capsules from the plates already on disk
```

Times on the 4-core SwiftShader build box (no GPU): about 1–2 min per 1080p shot, about 25 min for the whole set,
and 30–60 min for the video. On a machine with a GPU, all of it takes a few minutes. The capture is
deterministic: Math.random is seeded (`--seed`) and the game loop is stepped at a fixed 1/30 s, so a re-run
frames the same moments. If an agent changes the visuals, the same command picks the change up.

| Output | Contents |
|---|---|
| `store-art/screens/NN-<name>.png` | 1920×1080 gameplay screenshots **with the real HUD** (Steam / itch screenshot slots) |
| `store-art/plates/<name>.png` | The same moments with the DOM UI hidden (backgrounds for capsules, press kit). Not committed (`store-art/.gitignore`), regenerated by the capture |
| `store-art/capsules/*.png` | Steam header / small / main / vertical / library capsule, library hero (3840×1240 + 1920×620), page background, itch cover, OG image, key art, transparent logo |
| `store-art/capture/gameplay.{mp4,webm,gif}` | Fixed-step gameplay capture for the trailer edit and the Steam GIF slots |

Shot names: `title` (menu hero), `keyart` (title-screen hero camera mid-vigil, horde advancing under the moon,
plate only), `keyart-wide` (the same at 3840×1240 for the library hero), `horde` (~260 shadows vs. four evolved weapons), `night-pines`, `night-marsh`,
`night-ruins`, `boss` (Hollow Stag), `levelup`, `evolution` (reliquary reveal), `bearers` (vigil setup),
`hearth` (meta shop).

The capture also prints, per shot, where the bearer is on screen (`"bearer":"50%,49%"`), which is a quick check that
she is in frame. Note: as of 2026-11-04 the script works around a game bug where the bearer model does not follow
the simulated position during a vigil (`Player.update` lost its `group.position` sync in the sprint-1 refactor;
reported to the lead). The workaround does nothing once the game syncs the model itself.

How the staging works (so it stays honest): a veteran save is loaded (everything unlocked, hints off), a vigil is
started on the right night with the right bearer, and minutes of real simulation are fast-forwarded through
`Game.updateRun` with the bearer protected. Then the kit is topped up (the same effect as level-up picks) and a
crowd is spawned through the normal enemy spawner. A few frames are simulated so the VFX settle, and the shipping
renderer draws the frame. The hooks are `window.__game` / `window.__weapons` from `src/main.ts`. If a hook is
renamed, the affected shot fails with a message and the others still run.

`public/og-image.png` (social link preview) is a copy of `capsules/og-image-1200x630.png`. Copy it again after
regenerating.

## Voice

Voice guide for all copy: second person, present tense, short sentences, and warm with a little teeth ("Your
light is your life."). Use the in-world nouns: *vigil* (run), *bearer* (character), *relic* (passive), *Ash*
(meta-currency), *the Hearth* (meta shop), *the Gloom* (darkness), *shadows* (enemies). Never compare the game to
another title by name in store copy, and never borrow another game's logos, characters or look.

Tooling: `npm run package:web` (itch zip + sub-folder verification), `npm run package:desktop`, `npm run package:steam`.
