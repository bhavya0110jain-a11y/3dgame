## Definition of done for 1.0
1. No open S1/S2 bugs. S3s triaged with a written "won't fix for 1.0" reason.
2. 60 fps p95 with 300+ enemies at the default preset on the minimum-spec machine (Intel UHD 620 class), measured
   with `tools/perf.mjs` on real hardware, not SwiftShader.
3. A full run on each night is winnable and losable as designed (balance sim + 10 human playtests per night).
   Median first-win run between run 4 and run 8.
4. Signed, notarized Windows/macOS builds and a Linux build install and launch offline on clean machines. Steam
   Deck tested.
5. Store pages, trailer, press kit and capsules approved. AI disclosure and IARC rating done. Name cleared.
6. Saves survive version upgrades (migration test from every shipped save version).
7. `npm test`, `npm run typecheck`, the smoke test and `npm run package:web` (with `--verify`) are green in CI.

## Risks
| Risk | P | I | Mitigation |
|---|---|---|---|
| The art bar ("top-tier stylized AAA") isn't reached on WebGL within budget | M | H | Lock the art direction with the screenshot set at S1 end. Spend polish on the 10 store moments first. |
| Perf on min-spec iGPU with all effects | M | H | Auto-downgrade exists. Low preset drops AO/shadows/bloom. Measure early (S4, not S6). |
| Code-signing certificates take weeks (EV/OV identity checks) | H | M | Start the purchase/verification in S2. Azure Trusted Signing is the cheaper and faster option. |
| AI-content reception | M | M | Transparent disclosure + devlog about the human direction. |
| Name conflict | M | H | Clearance before Coming Soon (P0-11). 3 alternates ready. |
| Parallel-agent integration regressions | M | M | CI gate (typecheck/test/smoke/package-web --verify) on every integration commit. |
