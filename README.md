# Last Lantern

**Your light is your life.** A 3D action roguelite ("survivors-like") in a moonlit storybook night. You carry the
last lantern. Every hit dims it, the warm light around you shrinks, and the Gloom closes in.

- 15-minute runs · 3 nights with 3 bosses · 11 weapons with evolutions · 14 relics · 6 bearers · 13 Hearth upgrades · 24 achievements
- Keyboard & mouse, gamepad, touch · Low / Medium / High presets with automatic downscaling to hold 60 fps
- Ships as a **web build** (itch.io / web portals) and a **desktop build** (Steam / itch, via Electron) from one codebase

Design brief: [`design/gdd/game-concept.md`](design/gdd/game-concept.md) · Store copy: [`docs/store/`](docs/store/) ·
Roadmap to 1.0: [`production/milestones/v1.0.md`](production/milestones/v1.0.md)

## Quick start

Requirements: **Node.js 22+**, npm. For tests and screenshots: Playwright's Chromium (`npx playwright install chromium`).

```bash
npm ci                 # install (also downloads Electron, ~120 MB; set ELECTRON_SKIP_BINARY_DOWNLOAD=1 for web-only work)
npm run dev            # http://localhost:5173 — hot reload
npm run build          # typecheck + production build → dist/
npm run preview        # serve dist/ on http://localhost:4173
npm run desktop        # run the built dist/ inside the Electron desktop shell
```

## Test

```bash
npm run typecheck      # tsc --noEmit (strict)
npm test               # Vitest: unit tests (tests/unit), gameplay/render/VFX tests, balance simulation (tests/sim)
node tools/smoke.mjs <outDir>          # headless browser smoke test → screenshots (menu, setup, gameplay, level-up, combat, boss, game over, portrait/touch)
node tools/perf.mjs --counts 100,200,350   # frame-time benchmark at several enemy counts (use a real GPU)
node tools/playtest-bot.mjs --runs 3       # autonomous playtest bot, full runs
```
`DIST=<dir>` points the smoke test at another build folder. CI (`.github/workflows/game-ci.yml`) runs typecheck,
tests, the build and the itch-zip checks on every push and PR, then the browser smoke test and the itch sub-folder
boot check (perf is advisory).

## Ship

| Command | Output | Use |
|---|---|---|
| `npm run package:web` | `release/last-lantern-web.zip` | itch.io HTML5 / web portals. Builds, zips, then **verifies** in headless Chromium that the game boots from a deep sub-folder (as itch serves it) with 0 missing files and 0 console errors. |
| `npm run package:desktop` | `release/desktop/linux-unpacked/` (host OS `dir` build) | Steam depot content / local testing |
| `node tools/package-desktop.mjs --build linux:AppImage linux:tar.gz` | installers in `release/desktop/` | itch.io / direct download. Windows (`win:nsis`, `win:zip`) and macOS (`mac:dmg`) build on their own OS. See the CI template in `production/release/ci/release-desktop.yml` |
| `npm run package:steam` | same, with `steamworks.js` bundled | Steam achievements (optional, see `docs/store/steam-integration.md`) |
| `npm run package:icons` | `electron/assets/icon.{png,ico}`, `icons/*.png` | regenerate the app icon from `electron/assets/icon.svg` |
| `node tools/package-screens.mjs [--video]` | `production/release/store-art/`: 10 HUD screenshots, clean plates, 17 composed capsules (Steam, itch, OG, logo), gameplay mp4/webm/gif | store art captured **in-engine** and composed with the real logo. Re-run after visual changes (`docs/store/README.md`) |

Every package includes `THIRD_PARTY_NOTICES.txt` and `CREDITS.md`. `release/` is gitignored.

**Desktop shell** (`electron/`): loads the game offline from a privileged `app://game/` origin (so `fetch()` of models
and audio works and saves persist), starts fullscreen (**F11** / **Alt+Enter** toggle, remembered), single
instance, no menu bar, devtools and reload disabled in packaged builds, hardened Electron fuses, `--windowed` /
`--fullscreen` launch options. The page gets a small feature-detected API: `window.lanternDesktop`
(`quit`, `toggleFullscreen`, `openExternal`, `unlockAchievement`, …).

## Project structure

```
src/
  core/       engine-agnostic utils: events, input (kb/pad/touch), RNG, save, spatial hash
  render/     renderer + quality tiers, lighting, post-processing (N8AO, bloom, grading), VFX, camera, asset loading
  world/      ground, sky, grass, props, ambient particles (per-biome)
  entities/   player, instanced enemies, projectiles, pickups
  game/       game loop/state machine (Game.ts), director (spawns), upgrades, run state, achievements
  data/       data-driven content: weapons, evolutions, relics, enemies, biomes, bearers, Hearth, achievements
  ui/         DOM UI screens + HUD, SVG art, icons
  audio/      WebAudio mixer + generated audio manifest
public/       models/ (GLB, generated by Blender scripts), audio/ (OGG, synthesised)
tools/
  blender/    bpy scripts → GLB models (/home/user/blender-venv/bin/python tools/blender/characters/build.py)
  audio/      offline music/SFX synthesiser (Python + numpy/scipy + ffmpeg)
  smoke.mjs, perf.mjs, playtest-bot.mjs, balance-sim.ts      QA tools
  package-*.mjs                                              release packaging (web zip, desktop, icons, screenshots)
electron/     desktop shell: main.cjs, preload.cjs, steam.cjs (optional Steamworks), electron-builder config, icons
tests/        Vitest unit, gameplay and simulation tests
design/       game design documents (GDDs)
docs/store/   Steam & itch.io pages, press kit, trailer script, pricing & launch plan, Steam integration
production/   milestones, release checklist + CI template, QA reports, session state
.claude/      the AI studio: agent roles, skills, rules (Claude Code Game Studios template)
```

## How this game is made
Last Lantern is developed by an **AI game studio running in Claude Code**: specialised agents (game designer,
gameplay/engine/rendering programmers, technical artist, sound designer, QA, producer, release manager) working
in parallel under human direction. Models come from Blender Python scripts, audio is synthesised from scratch, and
there are no third-party art or audio assets. The store pages disclose that the game was made with AI.
